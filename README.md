# Портфолио IT-аналитика

Портфолио с примерами аналитических артефактов: описание задачи, архитектурный контекст, взаимодействия между системами и подход к проектированию API.

## Обо мне

Full-stack IT-аналитик. Работаю на стыке бизнеса и разработки: выявляю и уточняю требования, исследую текущее поведение систем, проектирую API и интеграции, описываю бизнес-правила и сценарии ошибок, сопровождаю разработку и проверяю функциональность перед выпуском.

В работе использую REST API, OpenAPI/TypeSpec, UML, Sequence diagrams, C4, SQL и документацию для разработки.

## О конфиденциальности

Материалы обезличены: внутренние названия систем, сервисов и клиентов заменены обобщёнными обозначениями. Схемы показывают логическую модель взаимодействия и не претендуют на описание всех деталей промышленной реализации.
